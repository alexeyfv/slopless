# Релизы

## v0.2.0

### Новый функционал

- **Многоуровневая маркировка артистов**.
  - Красная отметка, если использование ИИ обнаружено при помощи алгоритмов Deezer.
  - Оранжевая маркировка, если использование ИИ обнаружено при помощи алгоритмов Slopless.
- **Выбор базы данных с ИИ-артистами**:
  - Deezer и Slopless;
  - Только Deezer (артисты, у которых хотя бы один релиз сгенерирован ИИ);
  - Только Deezer (артисты, у которых 100% релизов сгенерированы ИИ).
- **Выбор действия для ИИ-треков**:
  - Доступные действия: «Дизлайк», «Дизлайк, если не лайкнуто», «Пропустить», «Пропустить, если не лайкнуто», «Ничего не делать», «Лайк».
  - Действие может быть отключено для не ИИ-треков. Полезно, если у артиста не все треки сгенерированы.
- **Локализация**. Теперь расширение поддерживает русский и английский языки.
- **Обновления в UI**
  - Улучшен UI расширения.
  - Добавлено всплывающее окно при наведении на метку.
- **Добавлена поддержка плеера новой «Моей волны»**.
- **Обновлена документация**. Добавлены страницы: «FAQ», «Обнаружение ИИ», «Релизы».

### Прочее

- Функционал автоматического добавления артистов в чёрный список отключён. В данный момент в базе более 140 тысяч ИИ-артистов и их число растёт каждый день. Если на 1 дизлайк будет тратиться всего 1 секунда, расширение должно работать без остановки больше 1.5 суток.
