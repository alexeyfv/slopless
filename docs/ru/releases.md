# Релизы

## v0.3.2

### Новый функционал

- Добавлен бот обратной связи для сообщений о неправильной маркировке.

## v0.3.1

### Исправления

- Исправлена зависающая маркировка.
- Исправлена проблема с двойным дизлайком (или любым другим действием).

## v0.3.0

### Новый функционал

- Slopless теперь использует свой собственный классификатор AI-музыки.
- Отдельный маркировка для ИИ-артистов и ИИ-треков.

## v0.2.5

### Исправления

- Исправлены действия «Пропустить», «Дизлайк» и «Лайк» вызванные изменением CSS-классов в плеере Яндекс Музыки.
- Селекторы элементов плеера теперь более устойчивы к будущим изменениям DOM.

### Прочее

- Обновлены зависимости.

## v0.2.4

Версия v0.2.4 была собрана, но не публиковалась в магазинах расширений. Изменения включены в v0.2.5.

## v0.2.3

Откат до версии v0.2.1 в Chrome и Firefox после исправления ошибки в файле с ID артистами.

## v0.2.2

Откат до версии v0.2.0 в Chrome и Firefox из-за ошибки в файле с ID артистов.

## v0.2.1

### Исправления

- Логика определения ИИ-треков перенесена из контент-скриптов в фоновый скрипт, что устранило дублирование кода и повысило надёжность.
- Исправлены крайние случаи определения статуса артистов.

## v0.2.0

### Новый функционал

- **Многоуровневая маркировка артистов**.
  - Красная отметка, если использование ИИ обнаружено при помощи алгоритмов Deezer.
  - Оранжевая маркировка, если использование ИИ обнаружено при помощи алгоритмов Slopless.
- **Выбор базы данных с ИИ-артистами**:
  - Deezer и Slopless;
  - Только Deezer (артисты, у которых хотя бы один релиз сгенерирован ИИ);
  - Только Deezer (артисты, у которых 100% релизов сгенерированы ИИ).
- **Выбор действия для ИИ-треков**:
  - Доступные действия: «Дизлайк», «Дизлайк, если не лайкнуто», «Пропустить», «Пропустить, если не лайкнуто», «Ничего не делать», «Лайк».
  - Действие может быть отключено для не ИИ-треков. Полезно, если у артиста не все треки сгенерированы.
- **Локализация**. Теперь расширение поддерживает русский и английский языки.
- **Обновления в UI**
  - Улучшен UI расширения.
  - Добавлено всплывающее окно при наведении на метку.
- **Добавлена поддержка плеера новой «Моей волны»**.
- **Обновлена документация**. Добавлены страницы: «FAQ», «Обнаружение ИИ», «Релизы».

### Прочее

- Функционал автоматического добавления артистов в чёрный список отключён. В данный момент в базе более 140 тысяч ИИ-артистов и их число растёт каждый день. Если на 1 дизлайк будет тратиться всего 1 секунда, расширение должно работать без остановки больше 1.5 суток.
